# Horizontes Venezuela 2050 · Mérida — Tablero de futuros

Página estática (un solo `index.html`) para el proceso de Mérida: universo de 132 señales en 13 clústeres, clasificación con votos y señales nuevas que agregan los grupos, rueda de futuros (Trascendencia) y plenaria. Las notas se guardan en Supabase y se ven en vivo en todas las pantallas.

## Publicar en Vercel
1. En vercel.com → **Add New… → Project** → importar `PeterIbarra/horizontes-2050-merida`.
2. Framework Preset: **Other**. Sin comando de build. Output: la raíz.
3. **Deploy**.

## Aviso
Cualquiera con el enlace puede leer, escribir y borrar notas. No escribir datos personales.

PNUD Venezuela.
